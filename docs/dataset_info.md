# Информация о датасете "Russian News 2020"

## Описание датасета

Датасет "Russian News 2020" содержит русскоязычные новости с заголовками и полными текстами. Датасет используется для обучения модели генерации заголовков к новостным текстам.

## Источник

- **URL**: https://storage.yandexcloud.net/google-colab-bucket/Datasets/russiannews_dataset.zip
- **Формат**: CSV
- **Размер**: ~10 000 примеров (для обучения)

## Структура данных

### Колонки

| Колонка | Тип | Описание |
|---------|-----|----------|
| `title` | string | Заголовок новости |
| `text` | string | Полный текст новости |

### Пример данных

```json
{
  "title": "Парад на Красной площади в День города",
  "text": "На Красной площади прошёл праздничный парад в честь Дня города..."
}
```

## Статистика

### Количество примеров
- **Общее количество**: ~10 000
- **Для обучения**: 10 000 (по умолчанию)

### Длина текстов
- **Минимальная длина**: ~50 символов
- **Максимальная длина**: ~5000 символов
- **Средняя длина**: ~500 символов

### Длина заголовков
- **Минимальная длина**: ~10 символов
- **Максимальная длина**: ~200 символов
- **Средняя длина**: ~50 символов

## Тематика новостей

Датасет охватывает разнообразные темы:
- Политика и общество
- Культура и искусство
- Спорт
- Технологии и наука
- Экономика и бизнес
- Образование
- Здоровье и медицина
- Погода и природа

## Предобработка данных

### Шаги предобработки

1. **Загрузка данных**: Чтение CSV файла
2. **Выбор колонок**: Оставляем только `title` и `text`
3. **Удаление пустых значений**: Удаление строк с пропущенными данными
4. **Удаление дубликатов**: Удаление одинаковых записей
5. **Ограничение размера**: Возможность ограничить количество примеров (по умолчанию 10 000)

### Качество данных

- **Пропущенные значения**: < 1%
- **Дубликаты**: < 2%
- **Аномалии**: Проверены вручную

### Формат для обучения

Данные преобразуются в формат:
```
<БОС> {заголовок} <ЕОС> {текст} <ЕОС>
```

Где:
- `<БОС>` - начало последовательности (BOS token)
- `<ЕОС>` - конец последовательности (EOS token)

## Ограничения

1. **Язык**: Только русский язык
2. **Временной период**: Новости 2020 года
3. **Качество**: Возможны опечатки и грамматические ошибки
4. **Баланс классов**: Неравномерное распределение по темам

## Рекомендации

### Для обучения
- Использовать 10 000 примеров для базового обучения
- Для более точной модели можно использовать весь датасет
- Рекомендуется использовать аугментацию данных для редких тем

### Для тестирования
- Использовать отдельный тестовый набор (20% от данных)
- Валидация на случайной выборке из 1000 примеров
